# Networking — знакомства на зале

**Рабочая ссылка:** https://networking-five-rosy.vercel.app (Vercel, обновляется сам при каждом изменении в `main`)

MVP нетворкинга для 500–600 гостей: QR → профиль → пары → поиск с чатом → разговор с одним вопросом на раунд.

## Изменения 20.11 (готовность к 500–600 гостям)

- **Фото отдельно от события.** Аватарки хранятся в таблице `photos` (миграция `002_photos.sql`) и отдаются по `/api/photo/:id` с кэшем браузера. Событие больше не раздувается: потолок 6 МБ не достигается даже на 650 гостях, экран зала получает килобайты вместо мегабайт.
- **Фото легче.** На телефоне сжимается до 320 px, примерно 20–40 КБ (на аватарке 48–112 px качество не страдает).
- **Профили не пропадают.** Все изменения события идут в транзакции с блокировкой строки (`mutateEvent`), одновременные входы и нажатия «нашёл» больше не затирают друг друга.
- **Без дублей.** Кроме ключа устройства, гость с теми же именем и компанией в этом событии попадает в свой старый профиль (другой браузер, Telegram → Safari, инкогнито, очищенный телефон).
- Старые события с фото внутри JSON продолжают показываться.

## Роли

| Кто | URL | Зачем |
| --- | --- | --- |
| Ведущий | `/` → создать событие → `/host/:id` | Раунды, таймеры поиска/нетворкинга, вопросы, старт/стоп, QR |
| Гость | `/join/:id` (QR) | Фото + имя + компания, поиск пары, чат, таймер с вопросом |
| Экран зала | `/screen/:id` | Летающие аватары в поиске; пары имя+компания без лиц в нетворкинге |

## Где код

Рабочее приложение — папка **`next-app/`** (Next.js + Postgres, локально PGlite). Старая версия на Express + Socket.IO удалена 20.11, она есть в истории git.

## Публикация

Опубликовать в Cursor (кнопка Publish), папка `next-app/`, visibility **public** — иначе гости без Cursor не зайдут. В проде нужен Postgres (`next-app/cursor-app.json`), таблицы создаются при сборке (`scripts/migrate.mjs`).

## Запуск локально

Нужен [Node.js](https://nodejs.org/) 18+ (лучше 22 LTS).

```bash
cd next-app
npm install
env -u DATABASE_URL npm run dev
```

Откройте **http://127.0.0.1:3000**. Без `DATABASE_URL` используется встроенная PGlite (данные живут до перезапуска).

## Сценарий раунда

1. Ведущий создаёт событие, показывает QR.
2. Гости регистрируются (фото, имя, компания).
3. **Старт раунда** → короткое перемешивание → группы по 2; при нечётном числе гостей одна **тройка**, никто не сидит в стороне.
4. **Поиск**: на телефоне видны **фото партнёров**; чат группы «где вы»; кнопка «Нашли».
5. **Нетворкинг**: таймер (по умолчанию 3 мин), один вопрос, чат группы остаётся; программа выбирает, кто спрашивает в первой половине.
6. Пауза → следующий раунд или финиш.

Вопросы по умолчанию редактируются в панели ведущего.
